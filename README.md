# Detecting-Racial-Hoaxes-in-Code-Mixed-Social-Media-Data
Official code for EM-26 at LT-EDI@LDK 2025. This repository utilizes fine-tuned mBERT (bert-base-multilingual-cased) to detect racial hoaxes and offensive language in bilingual, code-mixed social media datasets. The specialized processing pipeline handles erratic cross-lingual syntax to secure a 0.63 F1-score.
